# Body Make Gym LEAD 公式サイト

山口県下関市のパーソナルトレーニングジム「Body Make Gym LEAD」の公式サイトです。
まずはローカルで完結する静的サイトとして構築し、のちに WordPress テーマ **SWELL** へ移植することを前提に設計しています。

---

## 1. サイトの目的と設計方針

### このサイトの役割は「集客」ではなく「電子名刺・信頼醸成」

検索流入は Google ビジネスプロフィールが担っています。このサイトの役割は、
**Google で見つけた人が「どんなジムで、どんな人がやっているのか」を知って安心し、連絡すること** です。

そのため次の方針で作っています。

| 方針 | 具体的にやったこと |
|---|---|
| 情報の分かりやすさを装飾より優先 | 派手な演出を使わず、余白・行間・文字サイズで読みやすさを確保 |
| 煽らない | 「絶対痩せる」「〇kg減」といった成果強調表現を一切使用していない |
| クチコミは静かに見せる | 通販広告風のビフォーアフター演出を排除。最大3件のみ |
| 連絡手段は電話とLINEだけ | メールフォームは迷惑メール対策として**意図的に設置していません** |
| PC表示の品質を最優先 | 本文16px以上／行間1.8以上／コンテンツ幅は最大1120px／画像は比率固定で歪ませない |

### デザイン方針

- **ベースカラー**：黒（`#0B0B0C`）。文字はシルバー（`#B7BDC3`）を基調に、可読性が必要な箇所は白（`#F4F6F7`）。
- **アクセント**：サンド（`#D8CBB4`）1色のみ。派手な原色は使いません。ラベル・料金の数字・罫線の起点にだけ使用します。
- **書体**：見出しは明朝（Zen Old Mincho）、本文は角ゴシック（Zen Kaku Gothic New）。
  ジムサイトによくある「太い縮小ゴシック」を避け、「健康・長寿命」というテーマに合う落ち着いたトーンにしています。
- **シグネチャ（このサイトを象徴する要素）**：ジム紹介内の **「館内のご案内」写真ギャラリー**。
  ジム全体を大きく1枚見せたあと、自主トレスペース・有酸素運動スペース・キッズスペース・
  赤ちゃん用品という、このジム固有の設備を写真とラベルで並べています。
  文章で説明するより「どんな場所なのか」が一目で伝わることを優先しました。
  黒基調のページの中で、明るい白壁の写真が窓のように見えるのも狙いです。

### アクセシビリティ

- 見出しは h1 → h2 → h3 の階層を守っています。1ページに h1 は1つだけです。
  - `index.html` の h1 ＝ ファーストビューの「健康と、10年後も動ける身体づくりを。」
  - `price.html` の h1 ＝ 「料金」
  - 各セクションの見出しが h2、その中の小見出しが h3 です。
- 本文とのコントラスト比は約 10:1（黒地にシルバー）で、基準の 4.5:1 を大きく上回っています。
- すべてのタップ領域は高さ 48px 以上です。
- キーボード操作時のフォーカスリング（サンド色の枠）を全リンク・ボタンに表示します。
- 「本文へスキップ」リンクをページ先頭に用意しています（Tabキーを押すと表示されます）。
- `prefers-reduced-motion`（OSのアニメーション低減設定）に対応し、有効時はアニメーションを停止します。

### 差し替え手順

1. 上の表のファイル名で画像を用意する
2. `assets/img/` に**同じファイル名で上書き**する
3. 拡張子が変わる場合のみ、HTML 内の `src="assets/img/..."` を書き換える（`▼` のコメントですぐ見つかります）

### ファーストビューのスライドについて

`top-01.jpg` 〜 `top-03.jpg` が **3秒ごとに自動で切り替わります**（CSSのみ。JavaScript不使用）。

- **写真を差し替えるだけ**なら、同じファイル名で上書きすれば HTML/CSS の編集は不要です。
- **枚数を変える**場合は、`index.html` の `▼メイン写真スライド` 内の `<img>` を増減し、
  `style.css` の「ファーストビューの背景スライド」にある `animation-duration`（`9s`）と
  `animation-delay` を枚数に合わせて調整してください。CSS内にコメントで手順を書いてあります。
- OS側で「視差効果を減らす」が有効な利用者には、切り替えを止めて1枚目だけを表示します。

### 画質について

ファーストビューの3枚は、高解像度の元データ（`top001_1.jpg` / `top002_2.jpg` / `top003_3.jpg`、
2620〜3972px 幅）から **縮小して** 1920px 幅に書き出しています。

縮小はそれ自体で輪郭が締まるため、補正は最小限（軽いアンシャープのみ）に抑えています。
拡大処理を一切していないので、**画質の劣化はありません**。

> 参考：当初支給された `top001.jpg` 等（655〜993px）は拡大が必要で輪郭が甘くなっていました。
> 現在は使用していません。今後写真を追加する際も、**縮小で足りるサイズ（2400px 幅以上）** の
> 元データを用意してください。

館内写真5枚（`img001.jpg` 〜 `img005.jpg`、1024〜1508px 幅）は、表示比率（ジム全体は 3:2、
残り4枚は 4:3）に**先に切り抜いてから**書き出しています。切り抜きを CSS 任せにすると
画面幅によって切れる位置が変わり、見せたい機材やキッズスペースの床が画面外に出るためです。

`gym-05.jpg`（赤ちゃん用品）だけ、畳が画面の大半を占めるぶん他の4枚より暗く写っていたため、
並びが揃うように明るさを 6% だけ持ち上げています。それ以外の色調整はしていません。

現行サイトのような**引き伸ばしによる歪みは発生しません**。CSS で比率を固定しているためです。

## 7. SWELL への移植手順

このサイトは、最初から SWELL への移植を前提に作られています。

### なぜ移植しやすいのか

- 各セクションが独立した `<section>` で完結しており、**セクション間で依存する CSS / JS がありません**。
  1セクションずつコピーして貼り付けても崩れません。
- すべての CSS クラスに `lead-` プレフィックスが付いているため、**SWELL 既定のクラスと絶対に衝突しません**。
- CSS リセットやタグ直指定セレクタ（`body {}` `h2 {}` など）を使っていません（後述の 01 ブロックを除く）。

### 手順

#### ステップ1：CSS を「追加CSS」に入れる

1. `assets/css/style.css` を開く
2. **`01. 静的サイト専用ブロック` の部分（`html { ... }` と `.lead-page { ... }`）を削除する**
   - ファイル内に `★★★ SWELLへ移植するときは、この 01 のブロックを丸ごと削除してください` とコメントしてあります
   - ここだけがタグ直指定を含む部分で、SWELL ではテーマ側が同等の設定を持っているため不要です
3. 残り全部をコピーし、WordPress 管理画面の **「外観 → カスタマイズ → 追加CSS」** に貼り付ける
   - CSS の量が多い場合は、子テーマの `style.css` に置くほうが管理しやすくなります

#### ステップ2：Google Fonts の読み込み

`<head>` に以下を追加します（SWELL の「カスタマイズ → 高度な設定 → head内タグ」など）。

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Zen+Kaku+Gothic+New:wght@400;500;700&family=Zen+Old+Mincho:wght@400;600&display=swap" rel="stylesheet">
```

#### ステップ3：セクションを貼り替える

固定ページを「フルワイド」テンプレートで作成し、上から順に貼り付けます。

| index.html のセクション | SWELL 側の置き換え先 |
|---|---|
| ヘッダー（`<header class="lead-header">`） | **SWELL のヘッダー機能に置き換える**（ロゴ設定＋メニュー設定）。HTMLごと持ち込む必要はありません |
| ファーストビュー（`lead-hero`） | **SWELL の「メインビジュアル」機能**を使うか、カスタムHTMLブロックにそのまま貼り付け |
| ジム紹介（`lead-about`） | カスタムHTMLブロック 1個 |
| スタッフ紹介（`lead-staff`） | カスタムHTMLブロック 1個 |
| 選ばれる理由（`lead-reasons`） | カスタムHTMLブロック 1個 |
| 料金（`lead-price`） | カスタムHTMLブロック 1個 |
| お客様の声（`lead-voice`） | カスタムHTMLブロック 1個 |
| アクセス（`lead-access`） | カスタムHTMLブロック 1個 |
| 空き状況（`lead-schedule`） | フェーズ2で追加（→ 8章） |

`price.html` は、同じ手順で別の固定ページとして作成します。

#### ステップ4：JavaScript

`assets/js/main.js` の中身は次の4つです。

| 機能 | SWELL 移植時 |
|---|---|
| ヘッダーのスクロール状態 | **不要**（SWELL のヘッダー機能が同等の挙動を持つ） |
| ハンバーガーメニューの開閉 | **不要**（SWELL のモバイルメニューを使う） |
| スクロールフェードイン | **任意**。SWELL の「ブロックのアニメーション」設定でも代用できます |

つまり **SWELL に移植したあと、main.js は基本的に不要になります**。
フェードインだけ残したい場合は、`03.` のブロックだけを子テーマの JS として読み込んでください。

WordPress のメディアライブラリにアップロードし、`src="assets/img/..."` をメディアの URL に置き換えます。

## 8. フェーズ2（空き状況カレンダー）

### 今回のスコープ外です

独自の予約システム・会員システム・データベース連携は一切実装していません。
**外部の無料予約サービスを埋め込む**方針で、フェーズ2に実装予定です。

### 埋め込み予定位置

`index.html` の **アクセスセクションの直後、お問い合わせセクションの直前** に、
すでに枠だけ用意してあります。

```html
<section class="lead-section lead-schedule" id="lead-schedule" ... hidden>
  ...
  <div class="lead-schedule__slot">
    <!-- フェーズ2：外部の無料予約サービスを埋め込む予定 -->
  </div>
</section>
```

### 公開するときの手順

1. `<section ... hidden>` から **`hidden` を削除する**
2. `<div class="lead-schedule__slot">` の中に、予約サービスから発行された埋め込みコードを貼り付ける
3. ヘッダーとフッターのナビに `<a href="#lead-schedule">空き状況</a>` を追加する

現在は `hidden` にしてあるため、公開中のサイトに空の枠が表示されることはありません。

## 9. よく変更する箇所と、その場所

スマホからでも修正箇所を特定できるよう、HTML 内のコメント目印を併記しています。

### 料金を変える

| 変えたいもの | ファイル | 目印 |
|---|---|---|
| トップページの「¥4,250〜」 | `index.html` | `<!-- ▼料金：ここの数字を書き換えれば... -->` |
| 料金詳細ページの各金額 | `price.html` | `<!-- ▼パーソナルトレーニング -->` など、カテゴリごとの目印 |

`price.html` では `<span class="lead-plan__price">¥4,250</span>` の **数字部分だけ** を書き換えてください。
`¥` と `class` は消さないようにしてください。

> **税抜価格は書かないでください。** サイト全体を税込表示で統一しています。

### 営業時間・定休日を変える

`index.html` の `<!-- ▼店舗情報：住所・営業時間・定休日などはこの表を書き換え -->` を探し、
`<dd class="lead-infocard__dd">{{営業時間}}</dd>` の `{{営業時間}}` の部分を書き換えます。

営業時間と定休日は、他の項目より大きく太字で表示されるよう `lead-infocard__row--strong` が付いています。このクラスは消さないでください。

### 写真を変える

同じファイル名で `assets/img/` の中身を上書きするだけです（→ 6章）。HTML を触る必要はありません。

### クチコミを変える

`index.html` の `<!-- ▼クチコミ -->` を探します。

- **本文**：`{{Googleクチコミ本文1}}` の部分を書き換え
- **投稿者名**：`{{投稿者名1}}` の部分を書き換え
- **2件に減らす**：3枚目の `<li class="lead-voice-card">` から `</li>` までを丸ごと削除
- **星を4つにする**：5つ目の `<svg class="lead-star">` を `<svg class="lead-star lead-star--empty">` に変更し、
  すぐ上の `aria-label="5段階中5"` も `"5段階中4"` に変更

> クチコミは**最大3件まで**にしてください。件数を増やすと通販広告のような印象になり、サイト全体のトーンから外れます。

### 電話番号を変える

`index.html` と `price.html` の両方に出てきます（ヘッダー／お問い合わせ／フッター／アクセス）。
エディタの一括置換で `090-9416-4555` をすべて置き換えるのが確実です。
`href="tel:090-9416-4555"` の側も忘れずに変更してください（ここを変えないとタップ発信が古い番号のままになります）。

## 10. やってはいけないこと（設計上の約束）

このサイトには、意図をもって排除している要素があります。改修時は次を守ってください。

- **問い合わせフォーム・メール送信機能を追加しない。** 迷惑メール・スパム対策として意図的に排除しています。連絡手段は電話とLINEの2つだけです。
- **保育士・キッズスペースを「無料で必ず預かれる」と読める表現にしない。** 必ず「要相談」を添えてください。
- **自主トレスペースを一般利用可能と読める表現にしない。** パーソナル利用者限定です。
- **ジム名をテキストだけで表示しない。** ヘッダーとファーストビューでは必ずロゴ画像を使ってください。
- **セクションの順序を変えない。**
- **税抜価格を書かない。**
- **未確定の店舗情報を推測で埋めない。** 住所・営業時間・定休日・料金・クチコミ本文・トレーナー氏名・駐車場情報は、確認が取れるまで `{{ }}` のままにしてください。
